# PDI v0.6 engineering milestone evidence

> **Archived record:** this preserves the detailed self-hosted validation that
> preceded the public `v0.6.0` release candidate. Counts are historical
> evidence from one deployment, not installation promises or current public
> status.

## Operational hardening delivered

- Data Status & Freshness V0.1 added the historical `PipelineRun` ledger,
  bounded pipeline registry, formal single-lock runner, derived freshness
  signals, and a read-only MCP status Tool.
- Person Identity V0.1 mapped 417 stable PDI Persons from Immich's enumerable
  People inventory without names, face data, public references, or scheduling.
- Resource-Person Relation V0.1 created 10,460 active provider-owned `Resource
  depicts Person` relations across 5,267 Resources and 417 Persons.
- Typed Resource V0.1 retained `assets.id` as canonical while distinguishing
  `file` and `message` Resources.
- Gmail Provider V0.1 added bounded, read-only single-account message ingestion
  with RAW RFC 2822 Blob content and deterministic metadata observations.

Resource-Person relations contain only Resource identity, Person identity,
Provider provenance, and inactive lifecycle. The feature added no generic
graph, face/vector data, confidence, MCP capability, scheduler, or PipelineRun
entry. An explicit reconciliation command performs complete reconciliation.

The production migration head at the time was `3b1e6f8a4c20`. All 15,325
existing Resources were deterministically migrated to `file`; the migration
created no Message rows. Blob remained mandatory, file hash deduplication was
unchanged, and separate Provider Message identities did not auto-merge by
global content hash. Observation, Relation, public Resource references, and MCP
contracts remained unchanged.

Gmail validation created 283 Message Resources and Sources, complete RFC 2822
Blob coverage, and 1,132 current observations. The second formal sync produced
zero actions; the second enrichment processed zero and skipped all Resources.
Gmail API writes were zero. V0.1 remained single-account, unscheduled, and
unsuitable for unattended operation while OAuth application state was a
controlled-pilot constraint.

Initial and immediate idempotency syncs passed with zero duplicates or orphans.
Pairs associated with Immich Person identities outside the bounded Person
Identity scope remained excluded.

At the milestone, host-safe validation completed with `466 passed, 98 skipped`
and isolated PostgreSQL validation with `99 passed, 2 skipped`. Those counts
describe that historical commit only and are not the current release Gate.
