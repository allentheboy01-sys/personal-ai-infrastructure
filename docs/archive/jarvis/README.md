# Jarvis historical reference

Jarvis is an optional reference consumer of PDI. The repository temporarily
retains its runtime, Web application, deployment assets, designs, and validation
records to demonstrate a real consumer integration.

Historical Jarvis Stage/Gate documents remain in their original paths for link
stability during Public Readiness Phase A+B. They are removed from primary PDI
navigation and collected here conceptually as archive/reference material:

- [Stage 1 release](../../releases/jarvis-web-ui-v0.1-stage1.md)
- [Stage 5B E.1 release](../../releases/jarvis-web-ui-v0.1-stage5b-e1.md)
- [Stage 5B E.6 release](../../releases/jarvis-web-ui-v0.1-stage5b-e6.md)
- [Stage 5B E.8.4 release](../../releases/jarvis-web-ui-v0.1-stage5b-e8-4.md)
- the superseded Stage/Gate records under [`docs/design/`](../../design/)

These files preserve engineering history. They are not PDI Core architecture,
the public installation guide, or the PDI roadmap. Current reference-consumer
contracts remain discoverable from `docs/README.md`.

A later repository-boundary review may split Jarvis into a separate repository.
That split must preserve PDI's stable consumer boundary and zero dependency on
Jarvis.
